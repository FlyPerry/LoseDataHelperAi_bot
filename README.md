# 📥 Инструкция по импорту workflow в [n8n.cloud](https://n8n.cloud)

## ✅ Требования

- Аккаунт на [n8n.cloud](https://n8n.cloud)
- JSON-файл workflow'а (например, экспортированный из другой n8n-установки)

---

## 🔧 Шаги по импорту workflow

### 1. Вход в n8n

Перейди по ссылке: [https://app.n8n.cloud](https://app.n8n.cloud) и войди в свою среду.

---

### 2. Создай новый workflow

- В меню слева нажми **Workflows**
- Нажми **+ New Workflow**  
  (или открой уже существующий, если хочешь импортировать в него)

---

### 3. Импорт JSON

В правом верхнем углу нажми на значок **⋮ (три точки)** → выбери:

- **Import from File** – загрузка `.json` с компьютера
- **Import from Clipboard** – если ты скопировал JSON-код

---

### 4. Подтверди импорт

После выбора файла или вставки текста:

- Убедись, что workflow загрузился корректно
- Все ноды должны отобразиться на canvas

---

### 5. Сохрани и активируй

- Нажми 💾 **Save**
- Если хочешь запустить workflow — нажми **Activate**

---

## ⚠️ Примечания

- Если используются credentials/API, нужно **настроить их вручную**
- Проверь **триггеры**, **webhooks**, **интеграции** — могут потребовать повторного выбора
- Импорт никак не повлияет на уже существующие workflow'ы

---

## 📎 Пример

Хочешь — могу скинуть пример JSON-файла с простым webhook → ответом. Напиши, если нужно!
